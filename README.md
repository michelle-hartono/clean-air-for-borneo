# from taipei to palangka raya

Tracker for the air purifiers funded by Michelle's 25th-birthday donations.

## One-time setup

1. Create a new public GitHub repo named `clean-air` and push this folder to `main`.
2. Repo **Settings → Pages → Build and deployment**: Source "Deploy from a branch", Branch `main`, folder `/ (root)`. Save.
3. After about a minute the page is live at `https://<your-username>.github.io/clean-air/`.
4. Open that URL on your phone to check it loads. That URL is what goes in the QR code.

## Updating

Open the repo in Claude Code and say things like `order placed`, `on the way`, `received` with a photo, or `donations closed: NT$7,500, 2 purifiers`. See CLAUDE.md.
